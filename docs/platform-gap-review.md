## الاعتماديات والأولوية التنفيذية التالية

1. **Notifications التشغيلية الأساسية:** Native166 أكملت Payment/Enrollment منactual trusted transitions،معCentre/preferences/wording/history/Audit/current Lead ACL و178unit/93PG/57Browser و001–166 ناجحة. التاليNative167 Conversation Needs Attention منactual reason transitions وimmutable occurrence/no repeated unchanged reason/current-vs-historical/current access/UI/tests،ثمLead/unresolved/Integration-System alerts منscope مثبت دونتخمين،والقنواتالمفعلة/mandatory policies. لاAI/provider refinements؛كلجزءمتكاملثمcheckpoint.
2. **Automation:** typed versioned rules ومصادرoperational events الموثوقة وdurable per-rule execution/causation/loop guard،ثمactions تعيداستعمالApplication Services الحالية معcurrentrole/scope/business rules. Notification action تعتمدالخطوةالأولى. لاCustomer send منgenericHTTP أوsyntheticHuman.
3. **Analytics/Dashboard:** queries موثوقةمحدودةبالصلاحيات وfilters/drilldown/Conversion/per-currency وHuman metrics؛تغذيPerformance routing وAI Operations لاحقًا،ولااعتمادعلىLLMلحسابFacts.
4. **Search/Bulk وImport/Export ثمGoogle Sheets:** استكمالquery/column permission contract،ثمrow processing موثوقيعيداستعمالnormalization/Fields/intake؛Sheets connector فوقنفسservices وDB Source of Truth. إكمالmanaged Email/notificationchannels بالـmocks أثناءذلك.
5. **بقيةRequired behavior/acceptance:** Performance routing/Branch/User/Lead transfer/AI follow-up/returning/Operations/Form/Copilot/evaluations وبقيةcross-module requirements،ثمload/restore/security/startup/role UX. لا إسقاطأيFeature بسببترتيبالتنفيذ،ولاإدخالMollie أوoptionalprovider-specific refinements.
