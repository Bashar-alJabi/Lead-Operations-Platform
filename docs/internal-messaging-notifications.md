# إشعارات الموظفين عبر Messaging

تحدد المواصفات 03 §30 و02 §64 و06 §19 الفصل بين إرسال الموظفين ومحادثات العملاء. تستخدم القناة سجل Notification موثوقًا وصلاحية المستلم الحالية. يمكن للموظف إدارة اشتراكاته المسموحة، وللإدارة ضبط المرسل وصياغة القناة ضمن نطاقها.

يضبط Manager رقم Agent في فرعه، ويضبط Super Admin رقم Agent أو Manager في منظمته. يؤكد صاحب الحساب الرقم نفسه وموافقته من «حسابي». هذه موافقة شخصية على وجهة إدارية. تغيير الرقم يسحب الموافقة ويزيل تغيير نطاق الحساب أو تعطيله الوجهة. يظهر آخر أربعة أرقام فقط في الردود والسجل. تراجع صلاحية العضوية والجلسة والنطاق قبل كل تعديل.

يُخصص مرسل للإشعارات من إعداد Messaging لاتصال Branch. يجب أن يكون مرسلًا اكتُشف ويدعم القوالب. تمنع المنصة تخصيص رقم ترتبط هويته المادية باتصال آخر أو استُخدم في إعداد عميل أو محادثة أو استقبال رسالة عميل. تحفظ القاعدة الحجز وAudit وتزيل المرسل من اختيار عملاء الفرع في معاملة واحدة. يبقى الحجز عند تعطيل الاتصال للحفاظ على فصل callbacks المتأخرة.

يُتحقق من توقيع Meta قبل فصل callbacks في طلب يحتوي على عدة أرقام. تخزن أحداث المرسل الداخلي في سجل مستقل بمعرّف منع التكرار، يقتصر على نوع ووصول الحدث. تبقى تفاصيل الموظف أو الرد خارج CRM وقائمة مراجعة العملاء. قبول سجل callback في هذه المرحلة لا يثبت تسليم إشعار.

يضبط Manager قالب فرعه من «الإشعارات». يضبط Super Admin قوالب فروع منظمته. يجري الاختيار لكل حدث ولغة من القوالب المعتمدة في اتصال المرسل المحجوز. يقبل الربط نص BODY ثابتًا دون عناصر إضافية أو متغيرات. تخزّن قاعدة البيانات بصمة نسخة القالب لتمييز التعديلات اللاحقة لدى المزوّد. يضبط الموظف خيار الاشتراك واللغة لكل حدث بعد تأكيد رقم الحساب. يحتفظ النظام بإصدارات الإعدادات، وتخص كل نسخة الأحداث التي تلي حفظها. توفر الواجهة معاينة النص كما هو وسجلًا مقيدًا بالصلاحيات.

عند إدراج Notification Event موثوقة يضيف النظام عمل تجهيز لكل لغة ذات ربط نافذ في وقتها. يفحص `worker:notifications` جمهور الفرع عبر صفحات تصل إلى 25 مستخدمًا، ويثبت نسخة التفضيل والوجهة والربط والاتصال مع إيصال واحد لكل حدث ومستلم. تستلزم الأهلية موافقة الموظف وتفضيله الساريين قبل وقوع الحدث وصلاحية `notification_access` الحالية. يتراجع تجهيز الصفحة إذا تعثّر التدقيق، ويعمل تأخير تدريجي حتى توقف المهمة بعد خمس حالات فشل. لا توجد عملية I/O مع المزود في مرحلة التجهيز.

يعرض «نشاط Messaging الداخلي» سجل التجهيز الشخصي مع الحالة المشتقة من الإعداد الحالي ويخفي الحدث بعد فقدان صلاحية Lead. لا تتضمن القائمة رقم الموظف أو نص العميل. المرحلة التالية عامل التسليم الذي يحفظ المحاولة قبل I/O ويعيد الفحص، ثم يسجل إقرار المزود أو UNKNOWN.
